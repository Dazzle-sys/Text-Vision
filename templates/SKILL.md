# 视觉:把图片转成文字

本机文本模型(DeepSeek 等)看不懂图片,按需调 text-vision 工具:

1. **用户贴图** → 宿主已存为本地文件,消息带路径/文件名。**别拒绝、别索要路径**,自行定位(优先消息路径;找不到搜临时/项目目录最近图片)→ `describe_image(path)`;验证码/报错/文档截图优先 `ocr_image(path)`
2. **本地图片** → `describe_image(path, focus?)`
3. **主动截图看程序/界面** → 任务涉及运行中程序/窗口(问状态、看布局、验证操作结果、查报错)时**主动截图,别等用户**:`list_windows()` 拿清单 → 定 target → `screen_capture(target=…)`;界面动态,**关键操作后重截**;`clientArea=true`(仅 Windows)截客户区。护栏:截图传第三方 API,窗口含密码/账号/聊天/证件等敏感内容**先问用户再截**;找不到窗口会明确报错,确认进程在跑,别编内容
4. 拿到文字后继续分析,别读图片二进制
